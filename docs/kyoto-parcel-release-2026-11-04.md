# 京都の建物・地番対応の拡張

## 結果

PLATEAU全513,815棟を照合し、501,730棟に番号付き地番候補がある。176,204棟は単一区画内の幾何条件を満たす。郵便住所を独立確認した12棟とは異なる集計であり、全候補を確認済み住所として扱わない。検索対象は718,575筆、5,642町名、256分割。

Android 1.5.64 / PWA 1.6.36に検索と明示選択を実装。番地のない候補は除外し、複数の地番は選択肢として残す。建物変更時には前の地番選択を解除する。既存の住居・デモ割当・SOS位置・署名済み記録は一括変更しない。

## 検証

- Node検索・候補・住所登録の整合性・更新失敗の試験23件合格。JVM3クラス9件合格。
- Androidエミュレーターで同梱実データ31検索、建物対応と候補を検証。warm p95 260.24ms。
- ローカルChromeで検索→候補選択→保存→全市データ保存→圏外再読込→検索・保存が成功。warm p95 165.90ms。
- 全市保存は3,538ファイル、286,538,547bytes。うち新規の地番関連500ファイル。
- エミュレーターへのインストール完了。vivoは手元にないため今回は更新・実測していない。

- 伏見区淀生津町235-73から235-72へ1.668m移動する実形状の境界試験で、前の地番候補と出典が解除されることを確認。試験では地図の画素丸めだけを除外して正確な座標を入力。
- 公開検索データの同時40 HTTPクライアント取得が全件成功。66,611bytes/件、最大1,390ms。40台の実機試験ではない。

## 公開

検索・建物候補データをmainのb1d30daで公開。公開索引のSHA-256が生成物と一致することを確認。PWA Worker更新IDb158df9e893d40fdba48f0254a4f01ea、bundle SHA-256 352f2aa10bcc0f6c0bbdd4acda7cf4858bed029abfe530774f2d429652895939。比較ページは変更していない。

公開環境の最初の全市保存では旧来のriskタイル1件が一時的なネットワークエラーになった。保存済み版を維持することを確認し、ファイル単位で最大3回の再取得を追加した。明示的な停止は直ちに尊重する。恒久エラー時は旧版保持・手動再開を維持。修正後の公開PWAでも全3,538ファイル（286,538,547bytes）を保存し、圏外再読込・全角番地検索・候補選択・住居保存が成功。warm p95 160.30ms、初回検索3.87秒、JavaScript例外0件。測定はChromeの専用テスト環境であり、iPhone実機測定ではない。

## 熱海

[全市域調査](superpowers/plans/2026-11-04-tsunami-citywide-feasibility.md)を実施。358測量ファイルの取得、初島を含む市境との照合、拡大した本土側2領域の3m計算まで実行。全市をつなぐ海底測量が不足するため、市全域を計算・公開できたとは扱わない。公開済み0〜35mの36条件は変更していない。
