# メニューと設定の整理

既存の4タブとコンパクトヘッダーを維持し、住民が行いたい操作を入口にする。

## 設計

- 白 #FFFFFF、背景 #F5F8FB、本文 #183447、補助文字 #536478、操作 #155EEF、境界 #D6E0E8。ダークは既存テーマを使用。
- Androidの既存文字組、WebのNoto Sans JPとシステムフォントを維持。見出し23px、行16px、補足13px、左揃え。
- メニューは4つの主項目。細かな機能を同列に並べず、目的の画面内に置く。行全体を押せる。タップ領域48以上。

```
メニュー                         閉じる
自分の登録情報                   >
  名前・住居・建物と住戸
グループ                         >
訓練・地震                       >
アプリ設定                       >
```

自分の登録情報内に建物・住戸の入口を置く。設定には外観（端末に合わせる／ライト／ダーク）、言語、Androidの位置記録・保存地図、アプリ情報を置く。
訓練画面は開始操作を最初に置く。管理者以外にも「管理者が開始する」と次の行動を示す。地震報告は別項目にし、訓練と混同させない。会場デモ開始も訓練側に置く。

## 設計レビュー

カードを増やす案を採用せず、既存のシートと一覧行を使う。地域防災アプリで必要な「住居」と「訓練」を明示し、一般的な設定一覧への置換に留めない。権限・同期・記録形式は変更しない。

## 検証予定

メニューから各画面、外観の保存と再起動、管理者の訓練開始とメンバーの案内、320px・文字200%・英語、Android実機、公開PWA。実データ上で訓練を勝手に開始しない。
Browserプラグイン/skillはこのセッションに無いため、既存の許可済み専用Playwrightブラウザーを使う。

## 実装・検証結果

- Android 1.5.39 / code 52、PWA 1.6.13。4入口へ整理し、プロフィール内に建物・住戸の選択入口を移動。Androidは建物選択から戻るとプロフィールへ戻る。設定内の項目から戻ると設定に戻る。
- 外観を端末内に保存。システム／ライト／ダークを切替可能。Androidはステータスバーの文字色も反映、PWAは端末設定の変更にも追従。
- 訓練の管理者開始を先に配置。メンバーと未参加者には理由と入口を示す。会場デモ開始をグループ接続画面から訓練側へ移動。地震報告との区別、権限、開始条件は維持。
- PWA: プロフィール→建物→戻る、外観保存／再読み込み、OS追従、架空管理者の実際の訓練開始→安否回答可能、メンバーの案内、新規クラウド参加画面、会場デモ入口の6確認成功。400px、320px、1280px、320px文字200%英語で画像・操作確認。
- Android: ManagedTrainingFlowTest 3件、CompactHeaderTest 1件成功。ProfileGroupStateTestは旧メニュー名の検索で失敗したため新名称に更新し、再実行で1件成功。保存機能の失敗ではない。
- vivo・エミュレーターで4項目、登録→建物、訓練案内、ライト／ダークとアプリ再起動後の保持を確認。外観は試験前の「端末に合わせる」に復元。vivoのプロフィール・安否・グループの変更なし。
- 公開PWAは変更7ファイル一致。公開URLでも初回参加、メニュー、外観保持、管理者訓練入口を専用ブラウザーで確認。API通信を遮断し、サーバー記録の作成・変更なし。
- Worker version `05e54662-9673-4dd0-90be-69df42f18162`、deployment `c905067e-db13-4ee3-acc5-ec55f0ebfcb4`。バックエンドの3モジュールと既存保存先・設定を維持。

- iPhone実機およびVoiceOver/TalkBackの全読み上げ順序は今回未確認。指針の全項目への適合認証とはしない。
