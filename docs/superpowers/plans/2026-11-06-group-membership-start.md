# グループ参加と地震・訓練開始の分離

2026-11-06。利用者の確定指示：参加時のみパスワードを要求し、参加済みメンバーには管理者の地震・訓練開始が自動で反映される。新規グループの参加パスワードは作成時に管理者が設定する。Androidの英語凡例は `Map legend` に統一する。

## 変更

- PWA・Androidの開始画面から参加パスワード欄を撤去。先に無断で追加した「新しい参加者の受付（任意）」も撤去した。
- グループ作成画面で参加パスワードを設定する。PWAには既存の参加画面内に管理者用作成入口を追加した。グループ作成と開催開始は別操作。
- グループの参加認証を開催の設定から分離。開催前や開催終了後にもグループへ参加できる。既存の参加パスワードは使い続け、既存メンバー、過去の開催、安否・通報を保持する。
- 管理者だけが地震・訓練を開始できる。開始時に在籍メンバーへ配置を割り当て、既存の自動同期で新しい安否確認を取得する。参加者の再入力・再参加操作は不要。PWAを開いて使用中の自動同期は約15秒間隔。アプリを閉じた状態への新規プッシュ通知実装は今回追加していない。
- 作成時・参加時のパスワードをPWAの再送用IndexedDBやAndroidの再送用設定に保存しない。サーバーにはsalt付きハッシュを保存し、rosterには返さない。
- 更新前のクライアントとの互換性として、従来の初回開催時設定APIは受け付ける。新しい画面からは送信しない。既にグループ用の認証情報があれば開催開始の入力で変更しない。
- Androidの英語リソース `approved_legend` を `Legend` から `Map legend` へ変更。

## 検証

- Node回帰試験345件成功。認証不要の開催開始、権限のない開始の拒否、誤った参加パスワードの拒否、既存メンバーと履歴の維持、実Worker RPCとSQLite再起動を含む。
- 管理者と参加者を別ブラウザーコンテキストで作成。作成画面でパスワード設定→開催前に参加→管理者がパスワードなしで訓練開始→参加者に自動反映→終了→同じグループで地震開始→参加者に自動反映、を確認。
- 公開PWA静的資産でも成功。参加者の自動反映は訓練17.153秒、地震16.252秒。ページ例外0、作成・開始・安否の英語画面に日本語混入なし。公開資産はGETのみで取得し、テストのグループ・API・記録は使い捨てローカルサーバーで扱った。
- PWA 1.6.58公開・HTTP200・版表示確認。deployment `a0db698b57a0491eb3be01bebab374fb`、バンドルSHA256 `7df14f79877b067ac7376a0d1df46bc29a8daf5597cad0438580f37ebb040afa`。

## 以前の資料との差

以前の実装・試験には「開催終了後はパスワード参加できない」「開始画面でパスワードを必須入力」とするものがあった。今回の利用者指示に合わせ、グループへの所属と開催の状態を分離した。過去の比較列は履歴として残す。
