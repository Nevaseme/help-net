# 一般参加者のグループ退会

## 確定仕様

利用者が実装を承認。管理者は退会不可、一般参加者のみ対象。履歴の削除については「システム的に楽な方」との指示により、既存の通報・救助・集計の参照を維持できる履歴保持を選択した。

- Group → Group settings → Leave group。日本語はグループ → グループの設定 → グループを退会。
- 確認後、サーバーへの参加接続を停止し、会場の現在の配置から外す。参加枠は解放され、既存の無事の住民役の補充規則が適用される。
- 過去の安否・通報・救助・所属履歴は削除しない。画面は参加入口へ戻す。地図データ、言語、テーマ等は保持。
- 再参加はグループ名とパスワード、または有効な招待コードで認証する。同じ端末の本人を保持し、新しい接続資格に更新する。退会中に枠が使用された場合は空き枠を選ぶ。管理者による参加停止とは区別し、その停止を通常の再参加で解除しない。
- 開催前・開催中・開催終了後に退会できる。オフラインでは完了扱いにせず、再試行の案内を出す。
- 退会要求の応答が失われた場合は同じ資格で完了を再確認できる。復元コードは退会時に無効化し、管理者が新しく発行して復元した後の再退会も確認する。

## 実装

既存の`access` APIに`leave`操作を追加。既存の接続停止テーブルとmetadataを使用し、SQLスキーマの移行・既存グループの削除は不要。PWAは接続資格を解除して新しい未参加の表示領域へ再起動。Androidは接続資格・近距離共有キーを解除し、位置監視と共有を停止して未参加領域へ切り替える。

PWA 1.6.66 / r112、Android 1.5.89 / 102。URL変更、比較画面更新、性能最適化は行わない。
