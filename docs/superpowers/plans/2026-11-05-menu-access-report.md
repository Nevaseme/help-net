## 同期互換性

- ADMIN_STARTの権限検証と災害への投影をAndroid/PWA/サーバーで一致させた。
- 近距離共有はwire v19、HTTP記録APIはv8。旧クライアントが管理者の直接開始を読み飛ばして受信済みにしないよう、必要な更新を要求する。
- 過去の署名済みイベントや通常のREPORTによる成立条件は変更しない。
- 住居なしで参加済みの管理者が開始・回答・終了できる。本人確認は参加名簿による。
