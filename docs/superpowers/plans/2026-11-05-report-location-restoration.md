# 通報地点の復元・作業場所統合の実施記録

2026-11-05。対象はPWA 1.6.50、Android 1.5.76（89）。承認された「指示外の変更の撤去、作業フォルダー統合、GitHub更新、性能調査」に対応する。

## 実施した変更

- PWAのplaceReportMarkerとAndroidの通報位置探索、一律オフセット、引出線、建物を避ける再計算を撤去。通報の中心は登録座標の地図投影と一致する。
- Blocked road初期地点だけを `35.01078, 135.75824` に変更。御池通・室町通付近の道路上であることを地図で確認した。他の初期通報地点は変更しない。
- 保存済みデータは、管理者が取得する時に旧初期データと厳密一致する未編集のBlocked roadだけ訂正する。通報・資材・緊急度の3初期記録、作成者、時刻、地域、元座標と内容を照合し、訂正を新しい履歴として追加する。元記録を残し、利用者作成、編集、取り消し、追加フィールドのある記録は対象外。二重訂正しない。
- 建物輪郭をSymbolLayerより下に置く処理を維持。通報は地図上のUIとして描画し、地図からの開閉後もMap選択を保持する。
- 自動回避を要求したテストを削除し、登録座標との一致（2px以内）、アイコンの可視性、描画順、Map維持、連続移動を検証する試験へ変更。
- Androidの凡例が全面を占めて外側を押せない残りを修正。表示高を画面の80%までとし、外側タップで閉じることを実際の画面試験で確認。
- PWAで言語切替前の保存結果がSafetyに残るケースを修正。既知のUI結果文だけを切替後の言語へ変更し、氏名・住所・自由記述は翻訳しない。保存結果の文字色もテーマ変数へ合わせ、ダーク表示で読めない問題を修正。
- 旧比較の誤った自動回避説明を訂正し、画像の履歴を保持。右端にPWA 1.6.50とAndroid 1.5.76の実装確認列を追加。
- 公開APIと保存形式は変更していない。
