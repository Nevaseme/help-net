# 京都市の固定建物評価データ

## 採用した仕様

利用者の指示により、PLATEAU記事・公開ソフトウェア・技術報告を調査し、内閣府2025年南海トラフ地震の揺れによる建物被害関数を参考に、PCで独自計算を行った。IESの公式振動解析結果ではない。

計測震度5.0〜7.0を0.1刻みで持つ。木造6分類、鉄骨造6分類、RC/SRC造9分類の全壊・全半壊の公開グラフを数値化し、建物の構造・建築年・必要な階数と対応付けた。半壊のみは全半壊から全壊を引く。各建物に計算済みの分類を固定し、共通表を参照する形式で保存する。

利用者が選択した「16階以上は仮定を明記して被害率0」を優先して適用する。この場合は構造・年にかかわらず仮定による結果として保存し、曲線による結果とは区別する。通常の属性不足や対応しない構造は評価不明とする。

## PCで得られた結果

| 項目 | 件数 |
|---|---:|
| 京都市2025年度の公開建物モデル | 513,815 |
| 被害関数に対応付けられたモデル | 393,152 |
| 評価不明 | 120,648 |
| 16階以上のゼロ仮定 | 15 |
| 収録メッシュ | 242 |

固定データは83,137,350バイト（約83MB、244ファイル）。元GMLの合計は6,226,871,707バイト。京都市の公開整備範囲を対象とし、市内の全土地・全実在建物を網羅する意味ではない。原GML・成果物のSHA-256、出典URL、構造などの原値、評価不能理由を保持する。全モデルでLOD0外形を取得した。

評価不能理由には重複がある：構造不明107,349、建築年不明98,358、対応外の構造12,613、必要階数不明619。理由の合計を評価不明の棟数として扱わない。

## PlanDへの接続

- `android/app/src/main/assets/kyoto-building-assessment/` に固定データを収録。
- `BuildingAssessmentRepository` が通信なしで読込・検索し、`PlanViewModel.assessBuildingsAt` から参照できる。
- 位置を含む建物を外形と内周で照合。重なる建物は全件返す。不明は数値nullであり、被害率0へ変換しない。
- 震度は呼出側が明示する。未選定の想定地震を勝手に固定せず、曲線の範囲外は拒否する。
- 住民記録、手入力の建物、既存Roomデータは変更しない。画面・公開デモに新しい表示は追加していない。現状はデータと読込APIまでで、既存の強・中・弱への対応付けは未実装。
