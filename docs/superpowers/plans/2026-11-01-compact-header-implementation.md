# 承認された上部表示v2の実装

## 実装

- Android 1.5.38/code51、PWA 1.6.12。通常時は上部タイトルなし、訓練時は「訓練」、実災害時は「地震」。日時行と役割・所属の常設帯を撤去し、標準文字サイズで約64の1段表示へ変更。Androidの単位はdp、PWAはCSS px。
- 詳細は開始日時と経過時間のみ。町内会名・対象グループを含めない。所属・役割は既存の設定／グループ画面で確認する。詳細の開閉、下部タブ移動、フォーカス復帰を維持。
- 通信切断は上段右側の小さなNo internet。文字拡大時は読み上げ名付きの通信切断アイコンへ変更。表示枠を確保し、状態が変わっても地図を上下させない。
- AndroidはConnectivityManagerの既定ネットワークのVALIDATED状態をイベントで観測し、監視のための定期通信や加速度計測はしない。PWAはnavigator.onLineとonline/offlineイベントを利用する。PWAではOSと同じ到達性判定はできず、Wi-Fiには接続しているが上流だけが不通の場合などはNo internetを出せないことがある。同期失敗の詳細は従来どおりグループの共有情報に残す。
- 地域集計の入口は対応画面の活動欄の下へ移動。主要4タブ、安否・通報操作、津波表示、災害成立条件、データ保存先、通信権限は維持。

## 確認結果

- Androidのビルド成功。CompactHeaderTestは文字1.0／2.0で通信表示の有無によるコンテンツ位置不変と詳細ボタン操作に成功。実アプリのResponseDraftNavigationTest、ProfileGroupStateTestも成功。最初の通信表示テスト失敗はシステム言語の英語を日本語文字列で照合していたためで、実際の翻訳を使う照合へ修正した。
- エミュレーターで訓練の上部、時間だけの詳細、対応画面の地域集計、設定・グループへの往復を確認。Wi-Fi／モバイルを一時切断し、No internet表示と地図操作の座標不変、復帰後の表示消去を確認。元の無線設定を復元。UI Automatorでは文字ではなく日本語の読み上げ名で取得される表示を照合するよう試験を修正した。
- vivoを1.5.38へ更新。端末の通常の外部提供元確認を経て更新し、セキュリティ設定は変更なし。実データを編集せず、通常時の空タイトル、所属帯なし、設定・グループ・対応の地域集計への遷移を確認。vivoでは災害が選択されていないため、時間詳細はエミュレーターで確認した。vivoの通信設定は変更していない。
- PWA：上部、所属帯なし、時間のみの詳細、閉じた後のフォーカス復帰、通信切断・復帰による地図の座標と高さの不変、地域集計の入口、320px幅・文字200%・英語、通常時の空タイトル、実際のローカル地震記録からの「地震」表示を確認。架空データのみ使用し、公開グループに書き込んでいない。
- 公開PWAの8ファイル一致。公開URLに対する専用ブラウザーのメニュー遷移・4つの幅／文字・言語条件の確認も成功。ブラウザーの検証には、先に記録した内蔵ブラウザー取得失敗と利用者の許可に基づき専用Playwrightを使用。
