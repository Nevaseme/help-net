# 同期画面と未送信2件の調査（2026-11-01）

## 確認した原因

- 1.5.32では進捗バー挿入による上下移動を解消したが、自動同期中のbusyによって「今すぐ同期」の色が青から薄い無効色へ変化していた。色のピクセル比較で再現した。
- 1.5.33では同期ボタンだけ無効時も通常の配色を維持し、同期中の連打は従来どおり無効とする。進捗は既存ステータス欄が示す。
- vivoの未送信2件はプロフィールrevision5と位置revision85。サーバーはそれぞれrevision4・81、同期カーソルは双方75で未取得ページはない。どちらも他端末由来、同グループ名簿に所属し、署名原本なし・作成元の公開鍵登録なし。
- プロフィールの試験識別値が、10月31日にXiaomi 11T（1.5.22）で作成したSF-1522-X-OFFLINEと一致。位置取得時刻も同日の試験中。これは署名付き中継導入前の保存済み記録であり、署名の破損や同期ページ取りこぼしを示す証拠はない。

## 解消経路と現在の制約

Xiaomiの元グループDemo-1031でインターネット同期を実行すると、自分の記録として送信できる。vivoは次の取得で保存確認済みとなる。利用者は現在Xiaomiを操作できないと回答したため、2件は保全して待機。受信側が他端末の署名を代作する、無署名の他人の更新をサーバーで無条件受理する、保存確認を偽装する、記録を消す対応はしていない。

## 証拠

追記（利用者の削除指示後）：`LegacyFixtureCleanupTest`を明示指定で一度実行し、上記2件のローカル更新だけをサーバー確認済み版へ戻した。署名や送信確認を偽装せず、元の2件は端末内だけに復元用コピーを保存。未送信0、通常画面「同期済み」を確認。グループ・参加情報・他の記録は不変。Xiaomiには触れていないため、同端末から旧試験更新が再送される場合は再取得され得る。
