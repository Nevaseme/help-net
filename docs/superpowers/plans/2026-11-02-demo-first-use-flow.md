# 初回参加と会場デモの整理

対象：11月7日・六本木ヒルズのコンペ、および事前のチーム内リハーサル。一般公開の住民認証サービスへ拡張しない。既存記録は削除しない。比較ページは変更しない。

## 操作の流れ

- 参加者：グループ名・参加パスワード → 名前 → 無事／SOS → 地図。最初に会場・通常・招待・作成という種類を選ばせない。
- 招待コードと入れ直しの復元は「参加できないとき」に集約。初回参加に追加入力を要求しない。
- 管理者：Androidでグループ作成 → グループ画面内で位置モードと参加パスワードを設定 → デモ開始。開催中も同じ画面で人数・位置モード・終了を確認。
- デモの開始と終了はグループ画面に集約。通常の災害・避難訓練の操作とは別。終了→再開始で新しい安否回答へ切り替える。
- 位置モードは京都の架空位置／参加者の現在地。現在地は開始後の取得値のみ使い、未取得は位置不明。住居として保存しない。
- グループの活動地域、従来の招待、別グループへの切替、通信診断は補助設定へ。管理者の参加復元・停止も必要時のみ開く。

## 見た目

承認済みのアプリの白地・青・文字・部品を維持する。基本色は既存の primary（青）、text（濃い紺）、muted（補助文字）、border（薄いグレー）、surface（白）、danger（赤）を使用。新しい装飾用アイコンやブランドを増やさない。

見出し→短い状態→次の主操作→補助操作の順。入力は一列、既存フォント、既存の44px以上の操作高さ、左揃え。名前・パスワード・招待・復元を一画面に並列で入力させない。同期で入力や選択を作り直さない。

## 確認

専用ブラウザーで参加、復元、管理、2位置モード、繰り返し開始、圏外復帰を確認。Androidはビルド、権限・名簿・会場位置の単体試験、エミュレーターで公開サーバー接続と画面を確認。vivo未接続時は実機確認済みとは扱わない。
