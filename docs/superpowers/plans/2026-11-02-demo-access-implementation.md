# 会場デモ：参加・復元・位置モード・反復試験

対象は2026年11月7日、六本木ヒルズでのコンペと、事前のチーム内テスト。実在住民の身元確認や一般向け認証基盤への拡張は今回の範囲外。比較ページ・既存の利用者記録を削除／変更して置き換える作業ではない。

## 実装した流れ

- 参加者：グループ名・参加パスワード → 名前 → 安否 → 地図。招待と復元は「参加できないとき」の中。PWAに一般利用者向けグループ作成は表示しない。
- 管理者：Androidの「管理者としてグループを作成」→ グループ画面で位置モードと参加パスワード → 開始。開催状況と終了も同じグループ画面。既存の活動地域・旧招待発行・別グループへの変更は補助設定。
- デモは何度でも終了・再開始できる。グループとメンバーは保持し、毎回別の訓練IDを発行する。既存参加者にも新しいデモの選択を伝える。過去の回答を今回の安否として使わない。
- 京都モードは御所南〜烏丸御池の架空位置。現在地モードは開始後に取得した端末位置のみを利用。開始時に管理者が選び、途中で黙って変更しない。
- 現在地モードは参加前にも共有内容を説明する。PWAはブラウザーの位置許可、Androidは既存の位置記録とOSの許可を使用。未取得は位置不明のまま安否回答できる。住居情報への書き込みはしない。地図の初期閲覧位置の六本木周辺と、参加者の観測位置は別のもの。

## デモに必要な認証

- 既存のグループ分離・管理者権限チェック・HTTPS・保存時のハッシュ・参加試行制限を維持。
- 新しく設定する参加パスワードで、単一文字の繰り返しや代表的な弱い値を拒否。従来のパスワードを勝手に変更しない。これは網羅的な漏えいパスワード照合やNIST準拠の認定ではない。
- 本人用復元コードは32文字の文字集合から16文字の乱数（80bit）、24時間、1回限り。読み間違えやすいI/O/0/1を含めず、大小文字・空白・ハイフンは受理時に正規化。サーバーにはハッシュのみ保存。
- 参加者本人が事前に発行でき、控え忘れた場合は管理者が本人を確認して発行できる。管理者・班長の権限はこの復元機能で引き継がせない。
- 復元は同じmemberIdに新しい端末IDを追加し、過去のID・名簿履歴を保持する。名簿検証は一般メンバーの端末追加だけ許し、名前・役割・既知の履歴の書換えや、管理者端末の追加を拒否する。
- 古い端末資格はサーバーで失効。旧端末の署名付き代理投稿もサーバーで拒否。地図の表示枠は引き継ぐので人や点が増えない。復元後は現在の安否をもう一度回答する。元端末だけに残った未送信データを復元できるという意味ではない。
- 管理者は参加登録を停止できる。会場の地図から外し、記録は保持。誤停止時は管理者が新しい復元コードを発行して戻せる。名前だけで本人と判断して統合しない。
- 公開会場の一般メンバーは7日間サーバー利用がないと資格が期限切れになる。アクティブな利用は自動延長。管理者には同じ期限を適用せず、復旧担当を締め出さない。管理者の個別アカウント／パスキー化は未実装。
- 会場終了後は名前・パスワード経路だけでなく、旧招待コードによる新規加入と復元も停止。参加済み端末の記録取得は継続。通常の非公開訓練を終了しただけでは通常招待を停止しない。

## 制約

同一人物がコードを使わず意図的に新規加入する行為の完全排除はしない。共通参加パスワードは身元確認ではない。近距離通信が完全に圏外のときは失効を即時伝えられず、配信済み情報を遠隔消去するものでもない。住居情報の同期範囲は今回変更していない。参加コードと名前を知るだけでは既存参加者や管理者を復元できない。

### Android地図の検証環境

初回の画面試験では、マーカー情報・画像が正常でも画面上のアイコンが描画されなかった。最小の白背景でも図形は描ける一方で、標準注釈とSymbolLayerの両方のアイコンが消えた。MapLibre13.6.1→13.7.1の比較では解消せず、変更は戻した。

同じ13.6.1のアプリを、エミュレーターのSwiftShaderから`-gpu host`（Intel Arc）に切り替えて比較すると、標準注釈とSymbolLayerのアイコンが両方描画された。アプリ側の非表示時更新を遅らせる試行も効果がなく取り消し済み。地図描画・ライブラリの製品コードはこの調査では変更していない。画像比較は`demo-auth-1620/android-probe-*-local.png`、実行ログは`.implementation/demo-auth-render-probe-host.log`。診断専用の一時テストは削除し、本来の参加後マーカー描画試験をGPU描画で再実行して成功した。
