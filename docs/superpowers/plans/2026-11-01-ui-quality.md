# Web 1.6.17を基準としたAndroid・PWAの仕上げ

実装・検証済み（iPhone実機での再確認は別途）。対象は地図、一覧、対応・詳細・入力、安否、メニュー、設定、グループ参加。既存の保存・通信・災害開始条件は維持する。ユーザーは画面改善を許可し、完全な画素一致より読みやすさ・操作性を要求している。

## デザイン方針（実装前）

- 基準：保存済みWeb 1.6.17の27画面。4タブと採用済み参加画面を維持。
- 色：action #155eef、ink #183447、secondary #536478、surface #f3f7fb、SOS #e01f2c、safe #00836c。境界線は既存 #d6e0e8。
- 書体：Androidは既存Noto Sans JP。PWAはNoto Sans JPが利用可能ならそれを優先し、iOS・Androidの日本語サンセリフへフォールバック。見出し23–25、本文15–16、補助13以上を基本とする。入力16以上。
- 固定したヘッダーと4タブの間に、主内容を一つ置く。詳細はスクロールする本文と独立した主要操作を持つ。担当・進捗・緊急度はラベルと値を近接させる。
- 地図は表示面積を優先し、拡大・縮小・凡例・計算の操作が重ならないようにする。詳細を閉じる、タブを切り替える操作を常に残す。

```text
┌ メニュー  地震/訓練・日時 ┐
│ グループ          通信状態 │
│                            │
│ 地図 / 一覧 / 対応 / 安否   │
│ ┌ 詳細タイトル       閉じる┐│
│ │ ラベル 値 / 説明（scroll）││
│ └ 主要操作（固定）─────────┘│
└ 地図    一覧    対応   安否 ┘
```

## 公的・プラットフォーム規則の採用

- [デジタル庁・ボタン](https://design.digital.go.jp/dads/components/button/accessibility/)：名称、フォーカス、色に依存しない識別。
- [Apple HIG・Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) / [UI tips](https://developer.apple.com/design/tips/)：押しやすい操作領域、読みやすい文字、余白。PWAの小さな操作も44 CSS px以上を目標（Appleのptと同一の規格と主張しない）。
- [Android Compose accessibility](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)：48dpの操作領域、選択状態・役割を支援技術へ伝える。
- [GOV.UK error message](https://design-system.service.gov.uk/components/error-message/)：問題と修正方法を文字で伝え、保存済み表示とエラーを区別する。

## 事前批評と対応

1. PWAは34pxの地図拡縮、40pxの閉じる、10–11pxの補助文字が残る。操作領域と文字を拡大する。
2. Androidの対応詳細はラベルと値が別段落になり、履歴が常に全展開される。要点を近く配置し履歴は必要時に展開する。
3. PWAの詳細主要ボタンが本文中にあり、短い画面・キーボードで見失う。本文から独立し、可視領域に収める。
4. 文字拡大時に固定高ヘッダー・タブが文字を切る可能性。実際に拡大して折返し・操作到達性を検証する。
5. 基準は自治体サンプルを含むが、製品の実在しない地域集計を装わない。現グループの実データを同じ視覚階層で表示する。

## 確認範囲

PWA 320/400/430px、日本語・英語、文字拡大、短い画面、詳細→編集→保存/取消、キーボード・フォーカス、参加フロー。Androidは既存UI操作試験とエミュレーター・vivoの実画面。公開比較には架空データだけを追加。未検証のiPhone実機は検証済みとしない。

## 追記：同じ地図への津波重畳
利用者の指定により、津波操作を「無事を表示」と「位置不明」の間に置く。Androidの別MapViewを廃止し、安否・通報と同じ地図へ浸水深・範囲・基準点を重畳する。高さ入力は地図内の小パネルとし、折り畳んでも着色は残す。津波をオフにすると重畳のみを外す。PWAも同じ操作に揃える。0〜35mの既存計算結果を用い、計算方法は変更しない。

利用者の追加指定：無事表示を12sp相当に縮小し、津波ボタンの直後に数値入力欄とmを常設する。津波オン時は入力変更の350ms後に保存済みの該当高さを再表示。別の入力パネル・表示ボタンは不要。範囲外の値は着色を外して理由を表示する。

利用者の追加指定：津波ボタンのオン状態は濃い青#1246C6、白文字とする。浸水深の凡例色は変えない。

利用者の追加指定：地図上部の位置不明ボタンは人数を省略し、位置不明とだけ表示する。開いた一覧側の人数は維持。

追加指定：津波の説明枠を撤去し、凡例・条件・読込状況は既存の左下「凡例」に統合。「表示範囲」操作も撤去する。津波オンの色は#2F70DFへ明るく調整する。地図の自動表示と通常の中心復帰は維持。

追加指定：津波オンの背景は青#155EEFの不透明度18%（透明度82%）、文字は青#155EEFへ変更。左下凡例への統合・説明枠なしを維持。

追加指定：津波のオンオフ／高さ変更ではカメラの中心・倍率を変更しない。表示中の地図に浸水結果のみ重ねる。計算用基準点の青丸と凡例の青丸説明を除去。計算結果・地形・深さ配色は維持する。

追加指定：凡例は安否・津波の浸水深・建物評価の色／記号と短いラベルに絞る。計算詳細、出典、長い注意書き、結果IDは画面から除去。計算モデルや根拠資料は既存の技術文書に維持。
検証経路：Browser plugin not available。既存の専用Playwright環境で「地図→高さ変更→位置・倍率維持→凡例開閉」を確認。
