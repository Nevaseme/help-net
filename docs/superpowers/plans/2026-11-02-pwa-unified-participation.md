# PWAの参加導線と登録画面の統合（1.6.18）

## 依頼と範囲

一般のPWA利用者が参加しやすいよう、会場デモ／招待参加／グループ作成に分かれていた入口を統合する。公開比較ページは、利用者の2026-11-02の明示指示により今後は別途指示がない限り変更しない。今回も `demo/` とGitHub Pagesの比較ページは変更していない。Androidの変更は今回の対象ではない。

## 画面確認で見つかった原因

1. 旧PWAは初回画面でグループ作成を主に表示し、会場参加と招待参加が別々だった。
2. 普通の招待参加後は緯度経度の入力画面に進み、東京駅の座標が初期値として入っていた。
3. 15秒ごとの同期が利用者の操作と同じbusy状態を使い、ボタンを一時的に無効化していた。変更のない記録でも画面を描き直していた。

確認前後のスクリーンショットと結果は、非公開の作業用証跡フォルダー `pwa-parity-1618/` に保存。架空データのみ使用した。

## 実装した流れ

1. 初回は「グループに参加」。同じ欄にグループ名または招待コードを入力する。招待コードの場合はパスワード欄が消える。
2. 「次へ」で参加情報を確認して、表示する名前を入力する。参加画面から一般利用者向けのグループ作成を取り除いた。既存の管理者資格・管理機能は保持する。
3. 架空位置を割り当てる実施中の訓練・会場デモでは、参加方法によらず安否回答へ進む。回答保存後は同じ地図へ進む。
4. 住居が必要な通常の参加では「自分の登録情報」へ進む。住所・建物名検索／地図で選ぶ／現在地から選ぶを一か所にまとめ、ピンを確認して保存する。入力のない座標を0や東京駅として保存しない。すでに保存された住居を勝手に変更しない。
5. 参加済みのグループ画面には所属・活動地域を表示し、「別のグループに参加」と「通信の詳細」に整理。通信操作と初回登録を分離する。
6. 自動同期で操作ボタンを無効化しない。表示データが変わらなければ再描画しない。一覧の定期更新・地図マーカーも同じ内容なら維持する。実際の受信内容は反映する。

グループ名とパスワードの受付は既存のサーバーの名前参加方式を使用する。通常グループの招待コード方式も同じ画面で使える。PWAに新しいグループ作成の代替入口は設けていない。
