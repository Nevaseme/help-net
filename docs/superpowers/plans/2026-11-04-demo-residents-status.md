# 会場デモ住民・建物・状態表示の統合

ユーザーの2026-11-04指示を実装する。Web1.6.17の保存記録と、その後に確定した無事・救助済みの個人情報非開示を維持する。新しいタブや比較ページの変更はしない。

- 新規会場デモは64人。確認済み12棟の64個の配置点を使い、実住戸として扱わない。無事40、応答なし12、SOS6、救助済み6。聴衆の認証人数枠とは独立。既存開催中デモは上書きしない。
- 建物は登録住居の関係から人数を集計。無事・応答なし・SOS・救助済みを区別。氏名の行は町内会と公開時刻の既存制限を通した人だけ。応答なしの行から本人の記録位置へ移動し、住居位置を代わりに使わない。
- 無事・救助済みのタップは匿名の状態表示。救助済みは現在有効な救助記録の日時を表示。名前・住所・検知情報は表示しない。管理者の取消は元の記録を削除せず撤回記録を追記し、同時に複数の救助記録があれば全てを対象にする。
- 他人の救助記録の取消は管理者のみ。端末・サーバーでチェックし、過去の署名付き記録を変更しない。既存の自分の記録訂正は従来の範囲で維持。
- 英語住所はデモ12棟の確定した住所だけを対象に、町名の読みを出典で確認して表示変換。元の住所・位置・建物ID・自由入力の文章は変更しない。所在地の階はFloor 2、建物の階数は2 floors。

Android/PWAの状態表示・建物人数・位置への移動、管理者/一般参加者の取消権限、日英表示をテストする。UIは既存の詳細シートと色・アイコンを利用する。
