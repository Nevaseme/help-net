# 通常のグループ画面を整理

利用者の指示：自動同期・自動接続を前提に、通常ユーザーへ通信管理や旧iPhone/PC通信実験を見せない。

既存の白背景、文字#183447、補助文字#536478、操作青#155EEF、Noto Sans JPを維持する。左揃えの既存余白を使い、新しい装飾やタブは追加しない。

通常表示はグループ名・権限・作成／参加／招待／管理者の会場デモ操作。通信の状態・手動同期・Nearbyの手動操作・旧通信実験は、初期状態で閉じた「通信の詳細」の中にまとめる。初期権限要求と自動接続を行う処理は画面の展開状態から独立したまま維持する。登録失敗など利用者の操作に必要なエラーは隠さない。

確認：Android通常グループ画面に手動通信操作がない→詳細を開くと確認可能→閉じる→再表示しても自動共有が継続。エミュレーターとvivoで確認し、旧比較列を残して公開比較ページへ追加する。

利用者訂正（1.5.35）：旧iPhone・PC通信実験は、通信詳細にも表示しない。PlanAppのLabPanel呼び出しを撤去し、デバッグ版でも一般ユーザーの画面から開けない構成にした。ネット共有／近距離共有の詳細は残す。
