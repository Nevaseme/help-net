# Android地図の応答停止と通報・町内会の描画順

## 対象と原因

Android 1.5.86/code99、vivo V2417A、Android 16/API36。利用者から報告された16:30:56の終了は入力待ち5秒のANR、16:31:43はOS分類上JavaCrashだった。後者の付属トレースにも入力待ちタイムアウトが記録されていた。両方のメインスレッドは `placeBuildings → validHome → buildingResidentCounts → MapScreen` 内を実行中だった。

`MapScreen` は建物一覧を絞るたびに全住民・全建物の集計を再実行していた。建物100棟なら1回の画面更新で集計101回になる。各集計でも住民ごとに建物一覧を作り直すため、画面スレッドを長時間占有する。今回の記録は単純なメモリー不足による強制終了とは区別する。JavaCrashの例外クラスそのものは取得できておらず、例外終了の全原因まで確定したという扱いにはしない。

## 製品変更

- Android 1.5.87/code100。集計は住民・住居・救助・所属情報が変わったときに1回計算し、その結果を建物数と登録建物の判定で共用する。保存形式・住民の位置・表示権限・人数は変更しない。
- 通報の絵をSOS・無事と同じMapLibreの注釈層に統一。登録座標を中心に描画し、種類別の画像を再利用する。従来の48dpのタップ領域と読み上げ用の名称は透明な操作領域として保持する。
- 町内会の吹き出しをその上の描画層に置く。148×100dpの絵柄、文字、色、下端中央の固定アンカーを維持。位置探索・自動回避・補間は追加しない。画像は集計または言語等の変化時だけ生成し、地図移動では位置だけ更新する。詳細画面や地図操作ボタンの重なり順は維持する。
- PWA 1.6.61/r107。人物・通報は同じ既存markerPaneに残し、町内会を専用pane（675）へ移す。上下位置で変わる同一pane内のzIndexOffsetには依存しない。popupPane（700）等はその上。pane全体はタップを遮らず、吹き出し自身だけが操作を受ける。

## 試験

- Androidビルド・単体303件成功。既存の住民入りローカル開催で、地震・訓練それぞれの画面移動制限、初回案内、安否更新、地図移動・拡大縮小、全タブ往復、Show safe、位置不明、通報開閉とMap維持、ドラッグ閉じ、通報位置プレビュー・再選択が成功。
- `MapLayerDeviceTest` 成功（6.526秒）。通報とSOSが同じnative注釈層にあり、重なる吹き出しが画素として手前にあること、隠れていない通報の旗が実描画されることを検証。吹き出し・通報の実タップとカメラ移動8回も確認した。製品データ・サーバーへの書き込みなし。
- PWAはローカル資産/参加者32人と公開資産/参加者2人で地震・訓練を各試験。地図50人、Show safeオフ6人、位置不明2人、救助済み4人を維持。通報を吹き出し直下へ一時的に重ねたブラウザー試験で、描画・ヒットテストとも吹き出し優先を確認。日本語混入0、ページ例外0。公開サーバーには静的GETのみ、API操作は使い捨てのローカルJournal。
- 途中の試験失敗は保持：横向きで初回ボタンが画面外、既存試験の二重 `runOnMainSync`、新規試験のMapLibre初期化不足、横向きで通報の試験地点が画面外。試験条件・試験コードを訂正して上記を再確認した。アプリの不具合を試験成功として扱っていない。
- 最初の固定座標ADB操作は途中で画面回転したため、「6周すべて確認」の証拠にしない。最終試験は毎操作前のUIツリーから座標を取得する。
- 最終版の既存開催で、移動12回・拡大縮小各6回・People→Tasks→Safety→Mapの6周を149.4秒で完了。各周でMap選択と同一PIDを検査し、停止・再起動なし。終了履歴にもこの試験中のANR/例外終了はない。一時的な画面回転固定は試験後に元の自動設定へ戻した。
- 最終連続試験のPSSは開始438,452KB、各周550,540 / 545,146 / 620,219 / 615,442 / 536,689 / 617,514KB。RSSは開始654,267KB、終了840,619KB。地図・各画面を読み込む分の増加があり、単発測定からリーク解消とは断定しない。gfxinfoは5,287フレーム、p95 17ms/p99 93ms、deadline基準49フレーム（0.93%）、legacy基準2,329（44.05%）。指標の定義が異なり、MapLibreの全描画を測るものでもないため、「常に滑らか」とは結論しない。
- Web/共有処理の既存回帰試験350件成功。初回のローカル通信EACCESは実行環境の制約として記録し、ローカルサーバーを使用可能な実行環境で再試験した。
