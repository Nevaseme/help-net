# Android実機の更新・地図操作確認

2026-11-05、利用者のロック解除後に実施。端末はvivo V2417A、Android 16。既存データを保持して1.5.74（87）から**1.5.76（89）**へ更新し、インストール済み版を確認した。今回の作業ではアプリコード・保存形式・性能最適化は変更していない。

## 操作結果

| 操作 | 結果 |
|---|---|
| 通報のない範囲で地図を連続移動16回、拡大縮小4回 | 成功。4区間ごとにMapLibre地図が表示されていることをUIツリーで確認 |
| 通報のある範囲で地図を連続移動16回、拡大縮小4回 | 成功。確認地点の通報数は3→0→3→0→3。拡大時に画面外へ出て、縮小後に戻ることを確認 |
| 地図のBlocked roadを開く・閉じる | 成功。既存の道路閉塞内容を表示し、閉じるとMapを維持。記録の編集・対応開始は行わない |
| People / Tasks / Safetyとの往復 | 各3回、合計9往復でMapへ戻ることを確認 |
| 通報パネル上部のハンドルをドラッグ | 成功。下方向へのドラッグで閉じ、Mapを維持 |
| 応答停止・例外終了 | 有効な上記操作中に再現なし。開始から終了まで同じアプリプロセスを維持 |

終了履歴は更新前と最終確認で同一（SHA-256一致）。履歴には当日14時台の旧版ANR・例外終了が残っていたが、今回の操作に対応する新しい終了記録はない。試験プロセスのログにもFATAL EXCEPTION、OutOfMemoryError、Input dispatching timed out、Fatal signalは検出されなかった。

最初の計測は途中でSafety画面になっていたため、**地図の性能値として破棄**した。「未回答が原因」と一度説明したが、その後は安否を変更せずMapへ移動できたため、その原因判断は撤回した。以後は区間ごとに地図表示を確かめてやり直した。画面が切り替わった原因そのものは確定していない。

## 実機の限定測定

debugビルドの通常アプリを操作。`gfxinfo framestats`による集計で、全地図描画のGPU処理や長期使用を保証する値ではない。経過時間にはUIツリー・診断取得を含む。

| 測定 | 通報なしの移動 | 通報ありの移動 |
|---|---:|---:|
| 操作区間 | 18.66秒 | 19.12秒 |
| gfxinfoフレーム数 | 1244 | 1390 |
| janky frames | 3（0.24%） | 1（0.07%） |
| p50 / p95 / p99 | 8 / 13 / 17ms | 8 / 15 / 20ms |
| PSS開始→終了 | 453,376→653,883KB | 607,517→688,248KB |

9往復後のPSSは671,264KB、後続の静置確認では612,579KB。増加後の低下は確認したが、GC条件を統制しておらず、タイルキャッシュとメモリーリークの区別は未確定。メモリーの最適化・削除・キャッシュ変更は行わない。

地図操作時の30秒Perfettoトレースも保存（33,402,367 bytes）。今回は詳細なスタック・フレームタイムライン解析をしていないため、トレースから原因を特定したとは主張しない。
