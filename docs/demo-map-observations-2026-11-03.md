# デモの町内会地図・模擬観測・住居とスマホ位置の分離

## 要求と原因

- 利用者の補足により、PWAの地域集計には3町内会とも存在し、欠けていたのは地図上の他町内会の表示と遷移だった。
- web 1.6.17の採用基準には「他町内会のマーカー→統計・不足資材」「自町内会の統計吹き出しは非表示」「他町内会の個人詳細には進めない」と記載済み。PWAにその入口が未接続だった。
- 架空住民には安否・負傷・救助・通報があったが、衝撃・閉所の模擬情報とPWAの閉所表示がなかった。
- デモ住居の変更時、サーバー、PWA、Androidの投影処理が住居座標を模擬スマホ座標へ上書きしていた。

## 実装

- PWA地図に他町内会の名前・SOS・応答なしの吹き出しを追加。所属はデモ住居で判定。自町内会は吹き出しを出さず人物マークを表示する。他町内会の吹き出しは集計専用画面へ進み、人数・安否・負傷・通報・不足資材を表示する。個人編集欄は表示しない。
- 地図の吹き出しは人物・通報との重なりを避けて配置し、移動した吹き出しは線で集計対象位置と結ぶ。「対応→地域集計」は従来どおり3町内会全体を表示する。
- 各町内会の架空住民に衝撃・閉所の例を設けた。実参加者のセンサー記録は生成しない。PWAでは地図の右上が衝撃、左上が閉所、一覧・詳細にも表示。Androidも既存の観測表示へ接続した。無事・救助済みには表示せず、架空住民の詳細には「デモの模擬検知」と明示する。
- 開始済みシナリオは既存の人物ID・回答・住居を保持して読み取り時に模擬観測を補う。過去の署名付き記録を書き換えない。端末内の旧シナリオも同じ規則で表示できる。
- 住居変更は住所・建物・住戸だけを更新する。KYOTOモードの模擬スマホ位置は開始時の割当を維持し、ACTUALモードはGPS記録を使う。設定の住居ピンは変更後の住居座標を表示する。実住居の記録は変更しない。
- 起動途中に利用者が選択したタブを、初期化完了時に地図へ戻してしまう競合も解消。

- 専用ブラウザーでローカル版と公開PWAを確認。390×844、320px幅、日本語・英語、ページ例外なし。
- 参加→安否→地図→他町内会の集計、衝撃・閉所の印→模擬観測の詳細、住居変更→同期→再起動で住所とスマホ位置の分離、圏外再起動を確認。
- 既存の地域レポート、負傷更新、他端末の安否更新、圏外SOSの通信復帰、次の訓練への切替もローカルの複数ブラウザーで確認。
