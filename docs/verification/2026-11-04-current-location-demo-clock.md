# 現在地・津波英語表示・デモ配置・経過時間の確認

対象: Android 1.5.66 (79)、PWA 1.6.38。2026-11-04。

## 実装と操作

- 現在地は青い点とメートル単位の精度円。地図上の照準ボタンで移動する。自動取得による地図移動、住居・SOS・デモ位置の上書きは行わない。
- 津波の入力、検証メッセージ、読み込み、結果、浸水深凡例を英語化。高さ変更による自動移動なし。
- 検知ラベルは Impact / Enclosed space。Androidは最大2行でカード高さを揃える。
- 新規京都デモのスマホ位置を町内会の範囲内へ分散。住居は確認済み建物との対応を保持。既存デモはそのままなので、新配置には管理者による終了・開始が必要。
- 開始時の経過分数は初期値3分、0〜1440分を指定可能。開催中も管理者がグループ画面から変更可能。実記録の時刻や署名は変更せず、表示・開示判定にのみ適用。

## 試験時の問題と限界

当初の実機試験はUiAutomationの競合、その後ActivityScenarioによる試験画面の起動待ちで失敗・停止した。既存のshellComposeContent方式に揃え、別のUI操作を並走させず再実行した7件は成功。試験画面の終了でランチャーや背後の画面が見えることがあり、利用者の操作が原因とは判断しない。通常のMainActivityを再度開き、地図表示まで確認した。白い画面の報告全般を恒久解決したという判定ではない。

端末の現在地の絶対的な測位精度、iPhone実機、2台間の近距離通信は今回再測定していない。PWA現在地はブラウザーの制御された測位値での確認。vivoの実際の測位画面は非公開の一時ファイルにのみ保存し、Gitには追加しない。

旧説明の「スマホ位置=住居位置」は新しいデモには該当しない。住居の建物対応は維持したままスマホ位置を独立させた。旧デモを自動変換しない。
