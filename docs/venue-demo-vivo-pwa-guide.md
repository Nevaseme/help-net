# vivo管理者・PWAメンバーのデモ手順

手順更新日：2026-11-03。Android 1.5.56／公開PWA 1.6.26。今回のvivo・Mi 9T通信試験とiPhone確認の結果は、末尾の確認範囲と分けて記録する。

**現在の順序は「管理者がグループ作成 → デモ開始 → メンバーが参加 → 安否回答 → 地図」です。** グループ名・パスワードでの参加は、デモ開始後に受け付けます。開始前に参加者を待機室へ集める方式ではありません。チーム内の練習も本番も同じ手順です。

## 1. 準備

- 全員インターネットに接続する。APK導入・初回参加・地図保存は通信を切る前に完了させる。
- 管理者はvivoのアプリを使う。メンバーは [公開PWA](https://tasukeai-sync.tomodachi-takumi.workers.dev/) を使う。
- グループ名と好きな参加パスワード（例：12345678）を決める。メンバーへ渡す参加情報は、この2つだけ。
- iPhoneでホーム画面に追加して使う場合は、先に追加して、そのアイコンから開いて参加する。[Appleの追加手順](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)。

## 2. 管理者がvivoでグループを作る

1. 左上のメニュー → **グループ**を開く。
2. **管理者としてグループを作成**を押す。
3. **グループ名**と**あなたの名前**を入力する。名前はメンバーに表示される。
4. **作成してデモを準備**を押す。「デモを準備しましょう」と表示されれば作成完了。

既に別のグループに参加している場合は、手順2の前に **グループの設定 → 別のグループに参加**を開く。下へスクロールすると作成ボタンがある。以前のグループの記録を削除する操作ではない。

## 3. 管理者がデモを開始する

1. 同じグループ画面の「地図上の位置」で、次のどちらかを選ぶ。

   | 選択 | 表示 |
   | --- | --- |
   | **京都の架空位置** | 管理者も含め、御所南〜烏丸御池の建物へ分散表示。京都の地図・住所検索データを自動で準備する。活動地域の別設定は不要。 |
   | **参加者の現在地** | 各端末の位置情報を使用。虎ノ門ヒルズ周辺の地図・港区の住所検索を準備する。各自の許可が必要で、取得できない場合は位置不明。 |

2. **参加パスワード**を入力し、**デモを開始する**を押す。
3. 管理者自身も **無事**または**SOS**を選び、**安否を登録して地図へ**を押す。
4. メンバーへPWAのURL・グループ名・参加パスワードを伝え、「参加してよい」と案内する。

会場デモ中、画面上部は「訓練」と表示される。別途「地震」を開始する必要はない。

新しい会場デモには架空住民12人、通報3件、負傷あり2人、救助済み2人が入る。架空住民は京都の建物に紐づき、現在地モードでも虎ノ門の実在住民として扱わない。虎ノ門の建物形状は表示できるが、公開PLATEAUに建築年・構造が欠けるため、京都と同等の全壊率の色分けを見せる目的なら京都モードを使う。

## 4a. Androidの聴衆が参加する

1. QRの案内先から当日配布版APKをダウンロードして開き、提供元のインストール許可が出た場合は許可してインストールする。開発者向けオプションやUSBデバッグは不要。
2. アプリを開き、グループ名・参加パスワード → 次へ → 自分の名前 → **参加して安否を回答**。
3. 無事またはSOSを選び、安否を確定して地図へ進む。
4. 近くのデバイス・位置情報などアプリが求める共有用の権限を許可する。BluetoothとWi-Fi無線をオンにする。Android 10では周辺探索に位置情報の許可と端末の位置情報設定が必要。
5. Xiaomi・vivoなど対象端末では、参加・安否回答後に「再起動後も安否共有を続ける」と案内される。「設定を開く」からPlanD Mk1の自動起動を許可して戻る。あとからメニュー → アプリ設定 → 再起動後の安否共有でも開ける。Mi 9Tでは未許可だと再起動後の共有が始まらず、許可後の再起動試験で成功した。再起動後は一度ロック解除する。

※QRそのもの・当日APKの配布先は別途確定する。この手順書に未確認のAPK配布URLは記載しない。

## 4. メンバーがPWAで参加する

1. [公開PWA](https://tasukeai-sync.tomodachi-takumi.workers.dev/) を開く。
2. 案内された **グループ名**と**参加パスワード**を入力し、**次へ**を押す。
3. **あなたの名前**を入力し、**参加する**を押す。
4. 安否画面で **無事**または**SOS**を選ぶ。
5. **安否を更新する**を押す。地図が開き、自分と参加済みのメンバーが表示される。

この会場デモへの参加に、住所・建物・住戸の登録や招待コードの入力は不要。以前のグループが表示される人は、メニュー → グループ → グループの設定 → 別のグループに参加から進む。

## 5. 全員で確認する

- 管理者はvivoの **一覧**を開き、名前・人数・安否を確認する。
- メンバーはPWAの **安否**から回答を変更し、**安否を更新する**を押す。
- 他の人の地図・一覧に自動反映されることを確認する。毎回「今すぐ共有」を押す必要はない。
- PWAで通信復帰を試す場合は、画面を開いた状態で一度通信を切り、安否を更新してから通信を戻す。未送信の回答が自動共有される。
- PWA同士・PWAとAndroidはインターネット経由で共有する。PWAが圏外の間も近距離無線で他人へ送れる、という試験ではない。

### 圏外共有を見せる場面

1. 参加・地図保存が終わってから、Android参加者と管理者はモバイルデータをオフにし、会場Wi-Fiのアクセスポイントから切断する。自動接続も止める。Wi-Fi無線とBluetoothはオンのままにする。
2. Androidの一人が安否を変更して確定し、他のAndroidの地図・一覧に届くことを示す。
3. **対応**から新しい通報を作り、別のAndroidに反映することを示す。
4. PWA参加者は圏外でも自分の更新を保存できるが、その間の他端末への配信は行えない。通信を戻した後、PWAを前面に表示した状態で自動共有を確認する。「今すぐ同期」を毎回押す必要はない。iOSがPWAを終了・休止させた間の即時送信は約束しない。
5. 管理者の **対応 → 地域集計**で、町内会ごとの人数・安否・負傷者・通報・不足資材を見せる。**レポートを発行**でその時点の内容を保存し、**発行済みレポート**からHTMLを開く。

日本語／Englishはアプリ設定で変更できる。架空住民の名前・メモ・通報文・資材名はどちらでも英語。元データの住所は日本語のまま。

## 6. 終了・次の練習

管理者がメニュー → **グループ → デモを終了する → 終了する**を押す。記録は残る。

次回は同じグループ画面で位置モードと参加パスワードを設定し、**デモを開始する**。端末に参加情報が残っているメンバーは同じグループを利用できる。安否画面を開いて新しい回の回答を行う。新しく参加する人には今回のパスワードを渡す。

## 困ったとき

| 状態 | 確認・操作 |
| --- | --- |
| グループ名・パスワードが通らない | 管理者が先にデモを開始しているか、今回のグループ名・パスワードか、通信があるかを確認。 |
| 開くと以前のグループになる | グループ画面から「別のグループに参加」を開く。 |
| 地図に自分がいない | 安否回答を確定したか確認。現在地モードなら位置情報の許可も確認。京都の架空位置ならGPSは不要。 |
| Androidを再起動した後に近距離共有が戻らない | 再起動後に一度ロック解除し、Bluetooth・Wi-Fiをオンにする。Mi 9Tでは端末側の「自動起動」でPlanD Mk1の許可が必要（未許可時の起動拒否を実機確認）。自動起動許可後は、アプリを開かず再起動後のSOS・通報共有まで成功。 |
| アプリを入れ直した | 「参加できないとき → 以前の参加を復元する」を使用。自分の復元コードがなければ管理者に発行を依頼。 |

## 過去の確認範囲（今回の試験結果ではない）

実際のvivoで作成・開始し、独立したPWAブラウザー2つが新規参加、無事／SOS回答、3人の地図表示、vivoへの自動反映まで成功。PWAの圏外回答も通信復帰後に自動反映された。

PWAはPCのChromeをスマートフォン幅で使用した。今回iPhone実機を操作した結果ではない。参加者の現在地を使った屋内測位と、40人が一斉に操作する実機試験も今回の確認範囲には含まない。
