# グループ画面・開始操作の修正

- 対象：Android 1.5.51/code64、公開PWA 1.6.25/r47。比較ページは変更しない。
- 実機で6文字の入力と開始ボタンの無効状態を確認。8〜128文字という既存条件が画面に説明されていなかった。パスワード自体は取得・記録していない。
- 入力条件を常時表示。短い入力でもボタンを押すと、入力欄付近に必要文字数を表示し、開始要求は送らない。8文字以上の条件は変更しない。開始中だけボタンを無効化し、進行中と明記。入力の表示・非表示とキーボードの完了操作を追加。
- デモ準備と設定を同時に積み上げず、グループの主画面は位置・参加パスワード・開始に集約。設定、復元、通信の詳細を必要時に表示。Androidの市選択は別ポップアップではなく設定内に表示。
- 活動地域は市全域の地図保存と住所検索の優先地域。デモの参加者配置とは独立しており、開始必須条件ではない。その役割を設定画面に明記。
- Androidの位置設定とパスワードの下書きを設定画面の往復で維持。PWAもDOMを保持し、同期のたびに設定が閉じたり主画面へ戻ったりしない。
