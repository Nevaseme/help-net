# Android・PWA：確定済み画面との照合と復元

対象：Android 1.5.60、PWA 1.6.32。利用者から「人物詳細以外も、以前決めたデザインから勝手に省略・変更した箇所を修正」と指示された作業。

## 基準

- 別チャット `01a1730a-acec-7d41-8e9b-4af7419e2c8b` の記録を読み、保存済み Web1.6.17 の27画面・部品・対訳・ソースを基準にした。
- [確定画面と表示条件](superpowers/plans/2026-10-30-web-1617-design-baseline.md)。固定ソースは `aee4413cc8bf5a551b99e7a6a2586c79bea94b6f`。
- 後日の承認を優先する。コンパクトな訓練／地震ヘッダー、4タブ、整理済みメニュー、住所検索、地図上の津波入力、会場デモ、地域概況／負傷／資材／レポートは維持。
- [会場デモ計画](superpowers/plans/2026-10-31-venue-demo.md)の参加者名による相互確認は維持。通常運用の匿名条件を緩めない。画面には「架空住民」「模擬検知」の注記を戻さない。
- 公開比較ページ `demo/` は変更しない。保存済みの署名付き記録は変更しない。

## 画面別の差と対応

| 画面 | 見つかった差・対応 |
| --- | --- |
| 共通ヘッダー／4タブ | 後から承認された構成を維持。町内会／建物詳細を残したままタブが切り替わるPWAの不具合を修正。 |
| メニュー／設定 | 既存の整理済み構成を維持。PWAの説明・地図保存・画面戻りの翻訳漏れを修正。明暗表示を確認。 |
| 自分の登録情報／建物・住戸 | 住所検索と地図選択の統合導線を維持。英語時に日本語の操作文言が残る問題、登録済み建物の住民欄が公開条件を迂回する問題を修正。 |
| 地図 | Androidにも他町内会の集計マーカー・要約・不足資材を接続。個人の地図／一覧／対応で同じ町内会範囲を使用。元の衝撃・閉所の素材を使用。クラスタ境界は基準の14へ。 |
| 凡例／津波 | 後日承認された同一地図上の表示、メートル入力、移動しない挙動を維持。PWAの英語凡例とダークモードのスイッチを修正。 |
| 人物一覧 | 全町内会の安否統計表を復元。個人一覧は同じ町内会に限定。位置の経過時間と公開できる寝室を表示。 |
| 人物詳細 | Androidも固定された見出し・救助ボタン、住居／建物／昼間の場所／観測／履歴の順序へ。会場デモでも、位置が分かるSOSに住居を出さない。通常運用の3分前は匿名の観測を維持。 |
| 建物詳細 | 年・構造・階数と、実際の住居紐付け・公開条件に合う住民を表示。電話の近さだけで住民を決めない。 |
| 対応一覧 | 全員／自分／未担当と案件を維持。PWAの追加・CSV操作を下部に固定。地域集計から該当案件へ進める。 |
| 通報詳細 | 保存済みの地域を「未設定」と表示する誤りを修正。地域変更、公開可能な通報者情報、緊急度変更理由を復元。 |
| 通報作成・訂正 | 種類の自由入力と地域選択を復元。PWAは対応タブから直接フォームへ入り、地図で位置を選択。生の緯度経度入力を利用者に要求しない。地図との往復で入力を保持。 |
| 進捗／資材 | 4段階、引受済み・未着手の説明、担当外の注意、必要数・手配済み数、固定保存操作を復元。完了時の結果必須・競合時の確認は維持。 |
| 地域集計 | 全地域・町内会別の総数／SOS／道路閉塞／建物倒壊／その他を復元。統計は他町内会分も含め、リンク先は閲覧可能な案件に限定。建物損傷を倒壊に数えない。既存の人数／負傷／資材／レポートは残す。 |
| 他町内会 | 個人名や個人詳細へのリンクを出さず、安否4区分、高緊急度の未完了通報、資材不足、拡大、詳細を表示。 |
| 自分の安否 | 無事／SOS、SOSメモ、更新後の地図への導線を維持。入力文は翻訳しない。 |

新規発行する地域レポートは集計を保ち、閲覧範囲外の氏名・建物・座標を個人明細へ出力しない。CSVも画面で閲覧できる人物の範囲に合わせる。地図の他町内会要約では完了案件の資材不足を除く。過去の保存記録を改変する処理ではない。

## データ・権限との境界

- 自治体職員の認証と、別の実在グループの集計を取得する仕組みは未接続。見本の権限切替を一般利用者の画面へ移植したり、実在町内会の統計を作り出したりしない。会場デモでは承認済み3町内会の集計を表示する。
- 「普段昼間いる場所」の登録データがない場合は未登録。見本の勤務先を実データとして埋めない。表示欄を戻したことと、昼間の場所の登録・共有機能を完成させたことは区別する。
- 住所変更でSOS／電話位置が変わらない既存の分離を維持する。

## 検証

- PWA新規の隔離ブラウザー試験 `lab/test/design-baseline.browser.mjs`：日本語／英語、通常／ダーク、390px／320px、53画面、地域変更保存、通報下書きの地図往復、資材、進捗、安否、集計からの案件表示、圏外再起動。実サービスワーカーを使用。
- 既存 `lab/test/web1617-ui.browser.mjs`：通報訂正・取消・復元・同時更新、安否メモ保持、通常運用の3分前／経過後の表示が成功。現在の初回安否画面とフォームに試験手順を合わせた。
- PWAロジック最終版203件成功。CSVの人物範囲と完了案件の資材除外を含む。
- 公開PWAの隔離ブラウザー試験も115項目／53画面、失敗・ページ例外0。通報ボタンと案件行が31秒の待機中に置き換わらないことも確認。専用確認グループのデモは終了済み。
- 公開ブラウザー試験後の最終修正（救助済み住民の表示、CSVの人物範囲、完了案件の資材除外）は自動試験で確認。公開先から最後に変更した6ファイルを取得し、ローカルの検証済みファイルとSHA-256が一致した。
- Android最終版はJVMテスト269件成功、APKビルド成功。エミュレーターとvivoで、同じ確定画面の表示テスト各2件が成功。各端末の人物一覧・人物詳細・町内会要約／詳細の画像を保存した。
- vivoへAndroid 1.5.60を更新し、端末のAPKと最終ビルドのSHA-256が一致することを確認。通常のアプリを再表示し、既存グループと記録を保持している。APK SHA-256: `a2e33ff7cb54f27d5e6596dc3a72e279c97eb33989d27017a55d0874441a9d8d`。
- Androidの通報作成から取消・復元までの全操作試験は最終版で完走していない。途中版では操作を確認したが、試験手順の旧ラベルやエミュレーター起動待ちの問題があり、今回の最終端末確認は上記の画面試験と通常画面確認まで。iPhone実機での今回の最終版再確認も未実施。

画像と試験結果は公開リポジトリに含めず、ローカルの専用フォルダー `<local-evidence>/design-audit-full/` に保存。
