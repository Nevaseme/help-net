# 会場デモの参加パスワード

利用者の指定により、よく使われる文字列の拒否と8文字以上の条件を撤廃した。
`12345678`、短い数字、繰り返し、日本語を受け付ける。空欄・空白だけ・128文字を超える入力は受け付けない。
パスワードの照合では元の文字列をそのまま使う。大文字小文字や前後の空白を自動変更しない。既存のハッシュ・管理者認証・試行回数制限は維持する。

## 検証

- サーバーの開始・参加・権限・終了など18試験に合格。12345678、1、11111111、あ、前後空白を含む文字列を検証。
- PWAの既存試験187件に合格。
- 公開Workerの専用確認グループで12345678、1、あによる開始・参加に成功。各確認デモは終了済み。利用者のグループは変更していない。
- PWA 1.6.27、キャッシュ r50-demo-password を公開。比較ページは変更していない。
- Android 1.5.57で入力条件・説明を統一。
- Android通常版・テストAPKのビルド成功。エミュレーターの入力・開始・処理中操作の2試験に合格。初回はプロセス起動タイムアウトで終了したが、更新完了後の再試行で合格。
- vivoへ1.5.57（versionCode 70）を更新し、端末のインストール済み版を確認。

## 公開方法

Cloudflareプラグインで既存standalone Workerを取得し、検証条件2か所と埋込PWAの入力条件・説明・版・キャッシュを限定置換して更新した。置換前の件数を検査し、既存のDurable Object・レート制限・監視設定を引き継いだ。データ移行は実施していない。ローカルの対応するソースにも同じ修正を保存している。

既存のサーバー試験に不足していた保存ストアのreadモックも補い、現在の保存インターフェースに合わせた。
